## Featured Projects

**[sserver-c](https://codeberg.org/ottojvn/sserver-c)** — Simple HTTP server in C  
A lightweight HTTP server implemented in C using raw POSIX sockets and thread-per-connection concurrency with `pthreads`. Includes manual HTTP request parsing and local Make builds with compiler sanitizers (ASan, UBSan, LeakSan) and hardening flags.

**[femto-chat](https://codeberg.org/ottojvn/femto-chat)** *(in progress)* — Real-time AI chat application  
A real-time chat application with a NestJS/TypeScript backend providing a WebSocket gateway, streaming LLM responses via the Google Gemini API, and conversation persistence with Prisma and PostgreSQL, accompanied by an Angular frontend.
