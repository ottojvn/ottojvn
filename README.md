## Featured projects

**[sserver-c](https://github.com/ottojvn/sserver-c)** — HTTP/1.1 server built from scratch in C\
Concurrent architecture with `pthreads`, manual HTTP parsing over raw POSIX sockets, and a CI/CD pipeline with SAST, memory sanitizers (ASan, UBSan, LeakSan), and compilation hardening.

**[job_log](https://github.com/ottojvn/job_log)** — Full-stack job application tracker\
Next.js + Express + Prisma + PostgreSQL with GitHub OAuth via NextAuth. Includes Terraform modules for automated AWS provisioning (App Runner, RDS, ECR, Amplify).

**[erp-module-api](https://codeberg.org/ottojvn/erp-module-api)** — RESTful ERP microservice in Java 21\
Spring Boot 3 with layered architecture, DTO mapping via MapStruct, Jakarta validation, Spring Security, and test coverage with JUnit 5 + Mockito + MockMvc.

**[femto-chat](https://github.com/ottojvn/femto-chat)** *(in progress)* — Real-time AI chat backend\
NestJS WebSocket gateway streaming LLM responses from Google Gemini API, with conversation persistence via Prisma + PostgreSQL.
